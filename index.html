Open your dashboard

Browsers block an https page from talking to a LAN relay, so this button opens the dashboard straight from the relay over http instead.

First time

  1. On the PC: cd relay && npm install && npm start (or npm run sim for fake data)
  2. Copy the Dashboard http://… address it prints into the box above
  3. In the game, turn UDP telemetry on and point it at that PC

Game setup

F1 24 / 25 / 26Telemetry Settings → UDP on, port 20777, format 2024+
Forza Motorsport / HorizonData Out on, port 5300
